«Ապոլոն-11»-ի հրամանատարական մոդուլի (Comanche055) և լուսնային մոդուլի (Luminary099) բորտային կառավարման համակարգչի (AGC) կոդի բնօրինակը։ Թվայնացված է [Virtual AGC][3]-ի և [MIT Museum][4]-ի աշխատակիցների կողմից։ Նպատակն է ստեղծել «Ապոլոն-11» առաքելության կոդի բնօրինակի ամբողջական պահոց։ Ուստի ողջունվում են pull request-ները՝ կապված այս պահոցում առկա ֆայլերի և Luminary 099-ի ու Comanche 055-ի սկանավորված բնօրինակ փաստաթղթերի միջև հայտնաբերված անհամապատասխանությունների, ինչպես նաև ցանկացած այլ ֆայլերի, որոնք ես կարող էի բաց թողնել։

## Համագործակցություն

Խնդրում ենք pull request բացելուց առաջ ծանոթանալ [CONTRIBUTING.md][7]-ին։

## Կոմպիլյացիա

Եթե հետաքրքրված եք սկզբնական կոդի կոմպիլյացիայով, հրահանգները տեսեք այստեղ՝ [Virtual AGC][8]։

### Պայմանագիր և հաստատումներ

*Ստացված է [CONTRACT_AND_APPROVALS.agc]-ից*

Այս AGC ծրագիրը պետք է նաև հիշատակվի որպես Colossus 2A։

Այս ծրագիրը նախատեսված է հրամանատարական մոդուլում (CM) օգտագործելու համար՝ համաձայն `R-577` հաշվետվության։ Ծրագիրը պատրաստվել է DSR `55-23870` նախագծի շրջանակներում, որը հովանավորվել է ԱՄՆ Ազգային ավիացիայի և տիեզերագնացության վարչության (NASA) Մարդատար տիեզերանավերի կենտրոնի կողմից՝ Քեմբրիջում, Մասաչուսեթս, գտնվող Մասաչուսեթսի տեխնոլոգիական ինստիտուտի (MIT) չափիչ սարքավորումներ լաբորոտորիայի հետ կնքված `NAS 9-4065` պայմանագրի միջոցով։
